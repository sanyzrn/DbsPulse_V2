# آزمونِ سرتسریِ همکار DbsPulse

راهنمای کامل در [`README.md` اصلی، بخش «آزمونِ سرتسریِ همکار»](../README.md#آزمونِ-سرتسریِ-همکار-پوشهٔ-e2e) آمده است — خلاصه:

| فایل | نقش |
|---|---|
| `setup_e2e.py` | یک‌بار: سازمانِ نمونه، حسابِ `ai_hr`، وصل‌کردنِ تنظیماتِ همکار به مدلِ قلابی |
| `mock_llm.py` | سرویسِ سازگار با OpenAI روی `127.0.0.1:8100` با رفتارِ سناریومحور و قابلِ پیش‌بینی |
| `run_e2e.sh --api-only` | سناریوی کاملِ API: ورود ← بارگذاریِ اکسلِ ناقص ← پرسش‌وپاسخ ← تأیید ← ورود ← ممیزی |
| `e2e_browser.sh` | همان سناریو در مرورگرِ واقعی (Playwright) + نمایه‌ها در `e2e-screens/` |
| `e2e_api_test.py` / `e2e_browser.py` | خودِ سناریوها، جدا از راه‌اندازِ سرورها |

قبل از اجرا: مایگریشن‌ها روی دیتابیسِ محلی اعمال شده باشد و `DATABASE_URL` مثل بک‌اند export شده باشد.
