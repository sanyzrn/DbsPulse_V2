# NafasHR

سامانهٔ داخلی ارزیابی عملکرد شرکت دانش‌بنیان **نفس زیست فارمد**.

NafasHR فرایند ارزیابی عملکرد را از ثبت شواهد و امتیازدهی شاخص‌ها تا بررسی منابع انسانی، تأیید مدیران و صدور کارنامهٔ نهایی مدیریت می‌کند. این سامانه برای استفادهٔ داخلی نفس زیست فارمد طراحی شده است.

## قابلیت‌ها

- تعریف کارکنان، واحدهای سازمانی، شاخص‌ها و طرح‌های نمره‌دهی
- ثبت ارزیابی و شواهد توسط مسئول واحد
- گردش‌کار تأیید مرحله‌ای و بازگرداندن پرونده با ثبت دلیل
- خودارزیابی، مشاهدهٔ نتیجه و ثبت اعتراض توسط کارمند
- کارنامهٔ نهاییِ قابل چاپ و قابل استعلام با کد تأیید
- داشبورد، گزارش‌ها، خروجی Excel و گزارش رویدادهای غیرقابل‌تغییر
- مدیریت دوره‌های ارزیابی، برنامه‌های بهبود و اعلان‌ها

## معماری

- Frontend: React، TypeScript و Vite
- Backend: FastAPI و SQLAlchemy
- Database: PostgreSQL 16
- اجرا و استقرار: Docker Compose و Nginx

## اجرای محلی

پیش‌نیازها: Docker و Docker Compose، یا Node.js 20+، Python 3.12+ و PostgreSQL 16.

### اجرای کامل با Docker

```bash
cp backend/.env.example backend/.env
docker compose up --build
```

سامانه پس از آماده‌شدن سرویس‌ها در `http://localhost:5173` در دسترس است. پیش از استفادهٔ واقعی، مقدارهای امنیتی فایل `backend/.env` را با مقدارهای اختصاصی محیط جایگزین کنید.

### اجرای توسعه‌ای

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

در یک ترمینال دیگر:

```bash
cd frontend
npm ci
npm run dev
```

## آزمون و کیفیت

```bash
cd backend
ruff check .
pytest

cd ../frontend
npm run lint
npm test -- --run
npm run build
```

## استقرار

راهنمای عملیاتی استقرار در [deploy/PRODUCTION.md](deploy/PRODUCTION.md) قرار دارد. اطلاعات دسترسی، کلیدهای امضا و رمزهای محیط تولید را هرگز در مخزن ثبت نکنید.

## نام‌های فنی قدیمی

برخی نام‌های داخلی پایگاه‌داده و متغیرهای محیطی هنوز با پیشوند `dbspulse` باقی مانده‌اند تا داده‌های نصب موجود و مسیر ارتقا بدون ریسک حفظ شوند. این نام‌ها در رابط کاربری و هویت محصول نمایش داده نمی‌شوند.
